# DRD Portfolio Website

A responsive personal portfolio website for **Diptiranjan Das**, built using HTML, CSS, and JavaScript. The website is designed for both desktop and mobile screens and showcases personal information, education, technical skills, projects, and contact details.

## 📁 Project Structure

```text
DRD-Portfolio/
│
├── index.html
├── style.css
├── script.js
│
└── assets/
    ├── profile.jpg
    └── Diptiranjan-Das-CV.pdf
```

## 📄 File Description 

### `index.html`

The main structure of the portfolio website.

It contains:

* Navigation bar
* Home section
* About section
* Education details
* Skills section
* Projects/information sections
* Contact section
* Profile image
* CV download button
* Links to social/professional profiles

### `style.css`

Controls the complete visual design and layout of the website.

It handles:

* Colors and typography
* Navbar design
* Hero/Home section layout
* Profile image styling
* Buttons and cards
* Education timeline
* Skills design
* Contact section
* Animations and transitions
* Desktop layout
* Tablet and mobile responsive design

### `script.js`

Provides interactive functionality to the website.

It handles:

* Mobile navigation/menu
* Smooth scrolling
* Navbar interactions
* Scroll-based effects
* Interactive elements
* Dynamic UI behavior

### `assets/profile.jpg`

Personal profile photograph displayed on the portfolio website.

### `assets/Diptiranjan-Das-CV.pdf`

Downloadable CV/resume that visitors can access from the portfolio.

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet

The layout automatically adjusts according to the screen size for a better user experience.
